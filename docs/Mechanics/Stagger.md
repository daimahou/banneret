# Stagger

- Push every queued action of the target later.
- Successful stagger adds a stack and Staggered until the target's next action resolves; that action clears all stacks.
- Pushback = max(0, base − existing stacks).
- Zero pushback does nothing and adds no stack.
- Stacks are not consumed by another stagger. Skills may reward hitting Staggered targets.
- Bosses use the same rules; starting stagger exists only if authored.
- Timeline is continuous; beats are a shared cooldown and effect timer.

> [!frontier] Base pushback per skill
> The base also limits successive effective staggers before the target acts.

Colour family: red stagger pushes enemies later; green haste pulls the hero's actions earlier.
