# Over-time effects

| Effect | Rule in the brief                                                                                                                                                         |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Poison | Persistent stacks deal their count each beat. Healing is absorbed up to the stack count; absorbed healing removes half as many stacks. Remaining healing restores health. |
| Bleed  | Deals damage each beat, then loses one stack. Rupture exploits accumulated Bleed for immediate damage.                                                                    |
| Fire   | Flammability reaching a threshold ignites. Burning stacks deal damage each beat, then halve. Reignition refreshes rather than adds stacks.                                |
| Renew  | Stacks heal their count each beat, then lose one. Poison absorbs this like any healing.                                                                                   |

- Each status shows one number: stack count or remaining duration, never both.
- Red Bleed; green Poison; blue Fire; yellow Renew and purify; purple contagion.
- Purify turns ally debuffs into Renew. Contagion spreads existing Poison, Fire or Bleed.
