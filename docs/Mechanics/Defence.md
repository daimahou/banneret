# Defences

- **Block:** temporary flat protection from skills, removed after one or two beats; time it against visible intent.
- **Energy shield:** separate pool; each beat moves 25% toward its target, rounded down. Most heroes target zero. Mage armour raises the target to allow refill.
- **Evasion:** at most one charge; fully dodges the next hit, then must be earned back. No percentage chance.
- Absorption order: energy shield → block → armour → health.
- Red block, blue shield, green evasion. Armour is inherent; red armour break counters it.

> [!frontier] Values and shield rounding
> Values remain open. The stated example is 20 → 15 → 11 → 8; rounding the remaining value gives this sequence, while rounding the change down differs. Clarify before implementation.
