# Chain skills

- Schedule only the current state; several queued first-step copies remain first-step actions.
- Resolving advances the skill and makes the next state available.
- Queued actions retain their scheduled state.
- The chain advances only if no other action of the same hero resolved between steps; otherwise it resets after that step.
- Other heroes' actions and stagger do not break it.
- A chain belongs to one skill; combo is a generic spendable resource.

> [!frontier] Length and timeout
> Around three steps is suggested. Example: Slash → Double Slash → Flurry.
