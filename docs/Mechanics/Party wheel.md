# Party wheel

- Heroes near the centre; skill sectors around them; follower sections between hero areas.
- Skill placement follows acquisition order; adjacency does not gate combinations.
- Tiers grow outward.
- Show revealed trees and the next gate; hide distant paths.
- Keep earlier unpurchased nodes visible and available.
