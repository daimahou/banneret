Reward categories an event node could show on the mission map, besides artifact. Worth adding only together: categories must be equally worth having, and numerous enough that choosing a path for one is a real decision.

- **Shrine** — grants a colour, so the route picks the class direction. Moves colours out of level-up offers.
- **Trainer** — upgrades a skill or opens a node. Needs a clear difference from level-ups and skill points.
- **Scout** — eases the path: lowers fight levels, reveals a fight, cancels an earlier cost.
- **Boon** — strong temporary power for the next fight or two.
