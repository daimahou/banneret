## Done when

- The run starts with a fixed party of 3.
- Each event: the player picks a category, which selects a pool, then picks from a random offer drawn from that pool.
- One category is the boss buff event: the player dispels one of the boss's buffs.
- Events chain until one triggers an encounter.
