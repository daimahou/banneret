## How Steam Works

Too many games comes out: Steam filters out some games
Cannot determine which one will work - so there is an algorithm to do that.

Steam algorithm = Filter.

---

External traffic helps the algorithm determine what is the next hot thing: Wishlists.

Hopefully wishlists turns to sales - which is what drives the algorithm

---

Once the game is released, wishlist doesnt matter anymore - only the revenue counts. (~250.000$ with < 1 year = real steam)
